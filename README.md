# Modernization and AI Projects Overview

This repository contains three key projects focused on cloud modernization, AI governance, and AI infrastructure design.

## Projects

1.  **Cloud Modernization Study Project**
    *   **Description:** A basic migration strategy from on-prem to cloud, including a proposed containerization approach.
    *   **Directory:** `cloud-modernization/`

2.  **AI Governance Framework Project**
    *   **Description:** A sample AI risk assessment matrix and lifecycle oversight outline aligned with ISO 42001.
    *   **Directory:** `ai-governance/`

3.  **AI Infrastructure Concept Design**
    *   **Description:** An entry-level GPU cluster architecture concept with cost and scalability overview.
    *   **Directory:** `ai-infrastructure/`
